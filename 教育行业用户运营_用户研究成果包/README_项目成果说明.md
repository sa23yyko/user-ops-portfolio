# 教育行业用户运营｜用户研究成果包

**项目性质：个人独立模拟项目**
**数据性质：全部为模拟样本、模拟访谈记录与模拟编码，不代表真实用户调研结果。**

## 1. 你刚才学会并已经留存的成果

研究问题：
> 为什么用户下载/注册英语学习App后，没有形成持续学习习惯？

研究方法：
> 半结构化访谈 → 质性编码 → 痛点聚类 → 用户分层

样本：
> 8位模拟青年英语学习用户，覆盖四六级、考研、雅思、托福、职业证书、兴趣提升、职场提升、习惯打卡。

## 2. 核心用户运营产物

- 模拟用户样本库
- 40条模拟访谈记录
- 8条用户级质性编码
- 5类用户痛点聚类
- 4类用户运营分层
- 用户痛点频次可视化
- SQL查询示例

## 3. 适合放进作品集的研究链路

用户原话
→ 行为事实
→ 质性编码
→ 痛点主题
→ 用户分层
→ 运营含义

## 4. 简历/面试表达

不要写：
> “发现用户坚持不下来。”

建议写：
> “通过半结构化访谈与质性编码，将早期流失原因拆解为任务负荷、个性化、反馈、目标优先级和激励机制等可验证问题，并进一步完成用户分层。”

## 5. 数据边界

所有内容均为模拟独立项目数据，仅用于学习、作品集方法演示和面试练习；不应包装成真实企业项目成果或真实用户调研结论。

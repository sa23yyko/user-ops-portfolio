01
EXPERIMENT 01 / LOW-FRICTION FIRST TASK

低门槛首日任务

HYPOTHESIS / 实验假设

降低首次任务负担，让新用户更快完成一次完整学习闭环，可能提高激活和早期留存。

A / CONTROL

默认首次任务流程。

B / TREATMENT

“10 分钟即可完成”的低门槛首日任务：任务量更小；明确显示预计时间；完成后立即显示进度反馈；下一步可自主选择是否继续。

TARGET
新注册、尚未完成首次核心学习的用户。
PRIMARY METRIC
激活率：注册当天是否发生 start_learning；首日任务完成率：注册当天是否完成 complete_task。
SECONDARY METRIC
D1 留存；D7 留存；次日任务完成率。
GUARDRAIL
首日退出率；单次任务异常过短；用户主动关闭提醒比例；后续任务完成质量（真实业务需定义学习质量指标）。
PERIOD
至少一个完整周周期；真实上线前依据基线与最小可检测差异估算样本量。
DECISION
若激活率 / 首日完成率显著提高，D1 / D7 不下降，且护栏无明显恶化，再进入更大样本验证。
02
EXPERIMENT 02 / PROGRESS FEEDBACK

成长反馈

HYPOTHESIS / 实验假设

相比简单的“任务完成”，提供与个人目标相关的进步反馈，可能提升用户继续学习的价值感。

A / CONTROL

任务完成后仅显示“已完成”和本次学习数量 / 时长。

B / TREATMENT

任务完成后显示今日完成、距离个人目标的进度、最近学习连续性、当前薄弱项 / 改善项与下一步推荐任务。

TARGET
已完成至少一次学习任务的用户。
PRIMARY METRIC
次日再次学习率 / D1；D7 留存。
SECONDARY METRIC
周学习天数；每周任务完成数；下一任务点击率。
GUARDRAIL
页面关闭率；反馈页停留异常过长；推荐任务跳过率；用户对过度提醒 / 压力的反馈。
PERIOD
建议 2 周左右，覆盖至少一个 D7 周期。
DECISION
B 组 D1/D7 或周学习天数改善，且未增加压力型流失或跳过行为。
